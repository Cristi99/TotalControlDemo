# 🕹 TotalControlDemo
Demo of the game Total Control, which I made as a project for University. I made it using Unreal Engine's blueprints and created all the sprites, assets and backgrounds myself, using PaintTool SAI.

# 🌍 The World
The game takes place in a human version of the SpongeBob SquarePants world. You may notice how the world inspired me when I made the sprites and backgrounds for the game.

# 🎯 The Goal
Dr. Lankton's robots are out of control and you have to get to the control room in his secret lab and shut down the systems, before he takes over the world. You can defend yourself with your bubble gun and short-circuit any evil robot that gets in your way.
